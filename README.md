## Some things I've made

- **[16 Waves](https://github.com/alicewang453/16waves)** ([try it!](https://alicewang453.github.io/16waves/)): pick the sounds you like and get your personality type. Every sound is synthesized live in the browser with the Web Audio API. *Built with React, Web Audio API and Vite.*
- **[Swamp](https://github.com/ruan-xian/swamp)**: a functional programming language that compiles to LLVM, built with four friends. I was the project manager and taught it to handle strings and characters. *Built with OCaml, LLVM and C.*
- **[Bachelor Nation](https://github.com/quinnbooth/Bachelor-Nation-Flask-Site)**: a Flask site that walks you through a season of *The Bachelor*, mock rose ceremonies included. I built a lot of the server and the dialogue, rose ceremony and video pages. *Built with Python, Flask and JavaScript.*
- **[Pixel Plant](https://github.com/alicewang453/pixel-plant-game)**: a virtual houseplant you water and give light to with a real button and knob wired to an ESP32. *Built with Python, Pygame and an ESP32.*
- **[Loves Me, Loves Me Not](https://github.com/alicewang453/loves-me-not-esp32)**: a tiny hanging screen that plucks petals off randomly generated flowers until it lands on an answer. *Built with C++ and an ESP32.*
